# 책 목록 확장

다음은 기존에 확인된 코드 하나로 만든 최소 예시입니다. 새로운 책에는 실제 측정·검증한 코드를 넣으세요.

```json
{
  "schema_version": 1,
  "id": "my-collection",
  "title": "내 도서 모음",
  "description": "목록 설명",
  "adapter": "saypen-xor-book-v1",
  "books": [
    {
      "title": "Beep bepp",
      "tracks": [
        {
          "id": "beep-read",
          "mode": "Read",
          "raw_oid": 299000,
          "suggested_filename": "299000.mp3",
          "evidence": "실측 BLE 120299000, 실기 재생 확인"
        }
      ]
    }
  ]
}
```

- `raw_oid`에는 BLE 문자열 전체가 아니라 실제 숫자 값을 넣습니다. 이번 프로토콜의 `12` 종류 + `0299000` 값은 299000입니다. 다른 프로토콜에 이 분리 규칙을 무조건 적용하지 마세요.
- 현재 adapter는 100000~9999999의 책 선택 값만 받습니다. 일반 로컬 OID 방식은 별도 adapter 구현이 필요합니다.
- 음원 ID와 OID는 목록 안에서 중복되면 안 됩니다. ID는 영문 소문자·숫자·`-`·`_`만 허용합니다.
- `suggested_filename`은 자동 찾기용 파일명입니다. 경로·URL·스크립트는 넣지 않습니다. 사용자에게 이 이름의 파일을 다운로드해 주지 않습니다.
- 책별 모드는 1~20개, 전체 책은 1~200권입니다. JSON은 1MB 이하입니다.
- 새 목록은 UI에서 불러올 수 있습니다. 기본 목록으로 배포하려면 `saypen_pin/profiles`에 추가하고 재빌드하세요.
- 검증 순서: BLE 실측 → 파일명 분기 확인 → 단일 음원 생성 → 실기 확인 → 전체 목록 확장.
- 기여할 때는 측정한 코드와 검증 조건만 제출하고 음원·PIN·펌웨어·책 스캔은 올리지 마세요.
