# 세이펜 PIN 음원 파일 비공식 생성기

본 프로그램은 사용자가 정당하게 취득하고 해당 이용이 허용되는 음원을 호환 파일 형식으로 변환하기 위한 **비공식 오프라인 도구** 입니다.  
제조사 또는 출판사와 제휴하거나 이들의 승인을 받은 제품이 아니며, 음원·교재 이미지·제조사 펌웨어를 제공하지 않습니다.  
변환은 사용자의 기기에서 수행되며, 입력 음원과 생성 파일은 외부 서버로 전송되지 않습니다.  
타인의 권리를 침해하는 음원 사용이나 생성 파일의 무단 공유·판매에 이용하지 마십시오.  

## 준비사항

- 지원 도서의 MP3 음원: 사용자가 직접 보유하고 있는 정당한 음원 파일
- 세이펜 내에서 추출한 PIN 음원 샘플: 세이펜 SD카드 `BOOK` 폴더에서 선택

**앱에는 음원, PIN 템플릿, 펌웨어가 들어 있지 않습니다.**  
현재 방식은 사용자가 제공한 PIN의 구조를 활용하여 생성하므로 음원 파일만으로는 생성할 수 없습니다.  
동일 헤더 형식의 다른 템플릿에 대해서도 구조 검사를 수행하지만 실기 호환성까지 보장하지 않습니다.  

## 사용 순서

1. Windows 릴리스 ZIP을 별도 폴더에 풀고 **SoundbookPINMaker.exe**를 실행합니다.
2. **내 세이펜 PIN → 파일 선택**에서 정상 PIN을 고릅니다. 원본은 수정하지 않습니다.
3. **결과 저장 폴더**를 고릅니다. SD카드보다 PC 폴더를 권장합니다.
4. 왼쪽에서 책을 선택하고 각 구분별로 **MP3 선택**으로 해당 음원을 연결합니다.
   원래 숫자 파일명을 유지한 MP3는 **음원 폴더에서 자동 찾기**로 연결할 수도 있습니다. 같은 이름이 여러 개면 자동 선택하지 않습니다.
5. 자신이 이용할 수 있는 파일인지 확인하고 **선택한 음원으로 PIN 만들기**를 누릅니다. 한 개만 선택해도 됩니다.
6. 완료되면 **결과 폴더 열기**를 누릅니다. `BOOK` 안의 `.pin` 파일만 사용합니다.
7. 세이펜 SD카드를 백업한 뒤 해당 PIN을 카드의 `BOOK` 폴더 안에 넣습니다. 같은 이름 파일은 별도 보관한 후 교체하고, PIN 파일명은 바꾸지 않습니다.
8. 안전하게 분리하고 펜을 완전히 껐다 켠 뒤 일반 펜 모드로 확인합니다.

앱은 카드를 자동으로 수정하거나 펌웨어를 설치하지 않습니다. 파일을 만들 때마다 고유한 새 폴더를 사용합니다. 취소/실패한 `.partial` 폴더는 펜에 복사하지 마세요.

## 지원내역

| 항목 | 내용 |
|---|---|
| 펜/펌웨어 | RTR-4000BS / V0042 |
| 지원 도서 | Pictory 빼뜨르 호라체크 8종 보드북 × Read/Chant/Song |

## 새로운 책 추가

책 이름, 모드, 실제 OID, 추천 MP3 파일명을 담은 JSON을 **책 목록 추가**로 불러올 수 있습니다.
단, JSON만 추가한다고 모든 타사 펜 코드가 호환되는 것은 아닙니다. 현재는 세이펜의 같은 책 선택 경로를 사용하는 코드만 지원합니다.
[도서 목록 확장 방법](docs/CATALOGS.md)과 [구조 설명](docs/ARCHITECTURE.md)을 참고하세요.

## 개발 및 Windows 빌드

Python 3.11 이상과 Tcl/Tk가 필요합니다. python.org의 Windows 설치판에는 일반적으로 Tcl/Tk가 포함되어 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe run_app.py
.\.venv\Scripts\python.exe tools/build_release.py
```

결과 파일명에는 앱 버전이 들어갑니다. 버전 1.0.0에서는 `dist/SaypenPINMaker-1.0.0-windows-x64.zip`과 `dist/SaypenPINMaker-1.0.0-source.zip`입니다.
Windows EXE는 Windows에서 빌드합니다. GUI 실행에 필요한 패키지는 표준 라이브러리뿐이며 PyInstaller는 빌드할 때만 사용합니다.

공개 자동 테스트는 합성 프레임/임시 파일만 사용하며 실제 음원을 필요로 하지 않습니다.
개발 과정에서는 보유한 비공개 자료로 앱이 생성한 24개 파일이 기존 실기 성공본과 SHA-256까지 동일함을 확인했습니다.
개인 자료로 다시 대조하려면 `tools/verify_private_corpus.py --help`를 참고하세요. 입력이나 결과를 저장소에 넣지 마세요.

## 주의사항
**결과 PIN에는 선택한 음원과 템플릿 특수 음원이 들어 있으므로 앱/소스만 공유하고 결과 파일은 공개 배포하지 마세요.**
Windows 배포판은 코드 서명되지 않은 초기 버전입니다. 조직이나 Windows 설정에 따라 실행이 제한될 수 있으며, 보안 기능을 끄도록 안내하지 않습니다.
